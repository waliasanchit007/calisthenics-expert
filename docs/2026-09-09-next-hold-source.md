## Minimal reusable geometry, if a valid L-sit sequence is later found

Only the following image-plane observation is supportable from these pixels:
for one identified subject, both hand support points lie below the shoulders,
and each hip-to-knee-to-ankle chain can be tested for near-collinearity while
the thigh/leg chain is approximately horizontal in the image. A hold primitive
could therefore combine bilateral joint availability, hand-support visibility,

force, anatomical-range, or identity claim. It must remain separate from the
existing torso-still human-flag primitive.
